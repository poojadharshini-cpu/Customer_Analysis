# Retail & Customer Shopping Data Analysis

An end-to-end exploratory data analysis (EDA) and business intelligence project evaluating retail transaction data to uncover revenue drivers, customer purchasing behavior, and demographic trends.

## Business Objective
To transform raw retail transaction records into actionable business intelligence—identifying top-performing product categories, preferred payment methods, and key customer demographic segments to support data-driven inventory and marketing strategies.

## Repository Contents
* **`[customer_project.ipynb]`** – Python Jupyter Notebook covering data cleaning, preprocessing, statistical summaries, and exploratory visualizations.
* **`[Customer_Analysis.pbix]`** – Interactive Power BI dashboard displaying total revenue KPIs, category performance, payment mode distribution, and demographic breakdowns.
* **`[Customer_Data_Analysis.docx]`** – Comprehensive analytical report detailing methodology, key findings, and strategic recommendations.
* **`[Customer Data Analysis & Segmentation.pptx]`** – Executive presentation summarizing core insights and visual takeaways.

## Tools & Technologies
* **Python (Jupyter Notebook):** Data cleaning, null/outlier handling, feature aggregation, and exploratory data analysis (`Pandas`, `NumPy`, `Matplotlib`/`Seaborn`).
* **Power BI:** Data modeling, DAX measures, and interactive dashboard reporting.
* **Microsoft Excel:** Initial data inspection and cross-validation of summary metrics.

## Key Analytical Focus Areas
* **Revenue & Category Performance:** Evaluated total sales contribution and order volume across product categories to identify high-margin and high-demand segments.
* **Customer Demographics:** Analyzed purchasing patterns across age groups and gender segments to define core customer profiles.
* **Payment Behavior:** Assessed customer preferences across payment channels (e.g., Credit Card, Debit Card, Cash, Digital Wallets) to highlight checkout trends.

## Dashboard Highlights
* Dynamic KPI cards tracking **Total Revenue**, **Total Transactions**, and **Average Order Value**.
* Interactive slicers enabling drill-down analysis by **Gender**, **Age Group**, **Product Category**, and **Payment Method**.
